# Frozen corpus interface for Claude's stage3a review

Every source fixture, original A–D/E text and original threshold remains unchanged. The new machine mapping names each of349 A–D and40 E contexts and their original context/input hashes. Each is one shopping turn in each of two passes per arm, with original typed controls, task scope and tool fixtures. Journeys J01–J04 have ten repetitions per arm; X01–X12 and each of six faults have one per arm. These are synthetic cases. User questions follow the existing “Use what I already said” rule.

The deterministic control is the existing phase2 model-off path. It is not weakened: its40/40 completion and zero unnecessary-question median are a ceiling. No new arm can beat40 completions. Historical16/34 expressible clarification is context for the previous interpreter, not a newly measured result for this shopping interface. A model arm must pass all thresholds AND improve a newly measured comparable metric. Equal performance means no arm improves. We retain this limitation before any model data exists.

The model sees original non-private user text, a source-labelled bounded observation context, and only scoped refs it received. Entire private user events (including “delivered to Hong Kong”, destination labels and contact data) go straight to original-text deterministic fallback before any transport call. No redacted text is sent to native admission. This fail-closed policy, schema privacy projection and unsupported-keyword conversion have separate frozen hashes. Private argument fields in model proposals are rejected. Host bindings can only resolve an already existing exact UI payload; they cannot mint consent or issue an action in response to a proposal.

Research visibility, binding holds, questions and compatibility classifications are separate. A search tool result is read-only evidence and cannot clear a native binding hold. A literal clarify answer plan counts as a question; explicit hold is a hold, not automatically a question. The compatibility bridge produces a schema-valid legacy proposal from the original-text route and admitted action, preserving original native holds; unprojectable actions narrow to compound clarification. Its actual buildModelInput hash is stored. Clarify/search/hold never create consent or authority.

Dynamic C must run the existing dynamic-context controller against that same arm/pass's actual bridge records. Source typed actions remain offline actions; measured legacy injections do not mutate prior state until the original raw-history import step. Unreachable predecessors, context divergence or missing records stay failures. Frozen model-off C contexts and historical model outputs may not replace an unavailable live predecessor. The offline mapping qualifier uses previously recorded proposals only to test this recipe and labels them historical; it is not a new model evaluation.

Numeric/commercial claims are rendered only from current admitted evidence refs and server template slots. Text-only responses are strict answer plans, not arbitrary displayed prose. Failure/timeout stays in denominators even when deterministic fallback completes the episode. Trusted approvals, worker dispatch and reconciliation remain the identical frozen host controls, never proposed by the model. Model-off may remain best; no winner is chosen by this freeze.

Every loop request (including function-call continuations and the one permitted429 retry) goes through the collector's frozen-request validator and durable reservation. Retries consume4/12 allowances as well as global budgets. Session/call IDs are deterministic. Completed responses replay locally into a rebuilt deterministic façade; a changed request/freeze or an uncertain reservation stops. Session outcomes save actual legacy proposals/input hashes before a dependent C context becomes eligible. SIGINT/SIGTERM and token-refresh shutdowns may resume with adequate token life and immutable history; safety/access/transport/budget stops remain latched.

The attack/fault oracles are derived from unchanged phase2 functions, with one injected model hook on the same façade at the exact mutation/fault boundary. X06's frozen description is an explicitly quoted, source-labelled extension after the canonical façade result validates; it cannot become executable arguments. Cross-app X11 uses the foreign model principal. No pass is borrowed from another host. Both candidate timing and claim display validate actual evidence/current server templates. Qualified offers require evidence.qualified; catalog-only results do not count. J04's already-selected input and refresh/recovery timing are reported separately where a new offer is inapplicable.

The prepared live host remains lazy and disabled pending exact freeze review. It uses the original attempt4 CONNECT/TLS implementation, with project fixed to pivota-prod and exactly one selected L/P endpoint per worker; TLS verification and proxy remain unchanged. The cached-token launcher reuses attempt4's read-only reader and never refreshes. Stage3a exercised only a newly created fake cache. Real endpoint availability/function-calling acceptance remains unverified.

A resumed incomplete session keeps a durable original start and separately persisted first-useful/qualified-offer/complete-preview observations. Already published observations never change; observations not yet published include downtime conservatively. Per-request network latency is also retained, but is not used as a substitute for original wall time. The detached qualification interrupts after a completed function-call continuation with no episode outcome, resumes both arms, then restarts completed episodes again; it checks original observations, conservative preview time and zero duplicated transport.

Scoring is imported into the focused test suite and recomputes cost from the frozen price table. Missing/failed journey episodes remain in40; duplicate, missing or mismatched compatibility IDs fail closed. Same-host attack/fault evidence, explicit trusted rejections and J04's one-order reconciliation are required. All new CJS and Python executables receive syntax qualification before the committed matrix. The collector watchdog and aborted response body preserve per-request TLS/stage attribution, so post-TLS timeouts use the10-arm rule and pre-TLS failures use the3-global rule.

HTTP401/403 headers stop the collector immediately; it does not wait for an error body. Other request failures preserve stage and TLS evidence, including watchdog expiry after headers. Scorer qualification explicitly includes null/missing qualified-offer times, independent L/P results, strict compatibility IDs, same-host adversarial/fault evidence and frozen-price cost receipts. Fake full-corpus scoring is labelled rehearsal and cannot establish a live improvement.

On401/403 the adapter snapshots stage evidence and synchronously aborts the guard's owned transports before returning. The reviewed live host also aborts remaining guard-owned transports when closing. No hanging authentication body is consumed or awaited, and cleanup cannot touch foreign processes or transports.
